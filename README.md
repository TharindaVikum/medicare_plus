# Medicare Plus

Medicare Plus is a healthcare web application designed to manage hospital-related services and improve patient interaction through a modern and user-friendly system.

## Features
- Patient management system
- Appointment and service handling
- User authentication
- Responsive web interface
- Healthcare service workflows
- Clean and modern UI

## Technologies Used
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Modules
- User Login & Registration
- Patient Dashboard
- Service Management
- Profile Management
- Admin Features
